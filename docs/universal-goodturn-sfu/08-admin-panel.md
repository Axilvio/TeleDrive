# Universal GoodTURN SFU — модуль 08 (админ-панель)

## Что реализовано

- Простая admin-панель на Go templates + HTMX.
- URL:
  - `GET /admin`
  - `GET /admin/users?limit=100`
- Карточки метрик:
  - всего пользователей,
  - активные конфиги,
  - активные сессии,
  - pending-платежи,
  - pending-уведомления.
- Таблица пользователей с refresh через HTMX.
- Защита заголовком `X-Admin-Token` (если задан `ADMIN_TOKEN`).

## Комментарий

Это базовая админ-поверхность для операционного контроля. CRUD-интерфейс и массовые действия будут добавлены следующим модулем.
